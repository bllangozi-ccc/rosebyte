# Distribution boundary

This public repository has fresh distribution-only history. Core implementation lives in the private rosebyte-core-private repository. Never add compiler/runtime/hosted core source, native implementation, credentials, account data, recipient private keys or old plaintext git history here. Core updates must be sealed with the existing public release recipient using rb-release-key; never request or expose the owner's secret. Keep readable specifications/examples/docs and factual measurements public. Update the explicit distribution checker when adding an authorised artifact. Run python3 tools/check_distribution.py before committing. CI validates distribution integrity, not encrypted-core execution. Actual owner decryption and independent review remain separate acceptance checks.
